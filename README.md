# Jie Icons

自用 SVG 图标库，图标统一使用 `24 x 24` 画布和 `currentColor`，可以直接嵌入网页或通过远程 URL 调用。

## 目录

- `icons/arrows` - 箭头
- `icons/interface` - 界面控件
- `icons/actions` - 操作状态

## 远程调用

将文件推送到 `main` 分支后，可以使用 GitHub 原始文件地址：

```text
https://raw.githubusercontent.com/JieTk/my-icons/main/icons/interface/search.svg
```

网页中直接引用：

```html
<img src="https://raw.githubusercontent.com/JieTk/my-icons/main/icons/interface/search.svg" alt="Search">
```

## 本地预览

直接用浏览器打开任意 `.svg` 文件即可预览。
